# 第一次练习题
同学们可以按照自己的时间安排选择其中数道进行尝试。欢迎探索不同的证明方法，不必强求用真值表/代入规则/等值公式等证明。
## 第一章
证明下列公式为重言式
1. (1.4 例1) $(R \lor S) \lor \lnot (R \lor S)$
2. (1.4 例2) $((R \lor S) \land ((R \lor S) \rightarrow (P \lor Q))) \rightarrow (P \lor Q)$
3. (习题1 4(1)) $P \rightarrow P$
4. (习题1 4(2)改) $(P \lor Q) \rightarrow (Q \lor P)$
5. (习题1 4(3)) $(Q \rightarrow R) \rightarrow ((P \lor Q) \rightarrow (P \lor R))$
6. (习题1 4(4)) $(Q \rightarrow R) \rightarrow ((P \rightarrow Q) \rightarrow (P \rightarrow R))$
6. (习题1 4(5)) $(P \rightarrow Q) \rightarrow (\lnot Q \rightarrow \lnot P)$
8. (习题1 4(6)) $(P \land Q) \rightarrow (P \lor Q)$

## 第二章
证明下列等值公式
1. (2.1.1 例1) $(P \land \lnot P) \lor Q = Q$
2. (2.1.1 例2) $P \lor \lnot P = Q \lor \lnot Q$
3. (2.2.4 例1) $(\lnot P \land (\lnot Q \land R)) \lor (Q \land R) \lor (P \land R) = R$
4. (2.2.4 例2) $((P \lor Q) \land \lnot (\lnot P \land (\lnot Q \lor \lnot R))) \lor (\lnot P \land \lnot Q) \lor (\lnot P \land \lnot R) = T$
5. (习题2 1(1)) $P \rightarrow (Q \land R) = (P \rightarrow Q) \land (P \rightarrow R)$
6. (习题2 1(2)) $P \rightarrow Q = \lnot Q \rightarrow \lnot P$ 
7. (习题2 1(3)) $((P \rightarrow \lnot Q) \rightarrow (Q \rightarrow \lnot P)) \land R = R$
8. (习题2 1(4)) $( P \leftrightarrow Q) \leftrightarrow ( ( P  \land \lnot Q)  \lor ( Q \land \lnot P ) ) =	P  \land \lnot P$
9. (习题2 1(5)) $P \rightarrow (Q \rightarrow R) = (P \land Q) \rightarrow R$
10. (习题2 1(6)) $\lnot ( P \leftrightarrow Q) =	( P  \land \lnot Q)  \lor ( \lnot P \land Q)$
